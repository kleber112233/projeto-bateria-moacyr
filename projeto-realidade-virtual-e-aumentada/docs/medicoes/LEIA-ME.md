# Medições

Arquivos gerados pelo botão **"Salvar arquivo na máquina"** da página (depois de informar o nome da máquina).

- Um arquivo por medição: `medicao_AAAA-MM-DD_HHMM_nome-da-maquina.txt`.
- Cada arquivo traz a máquina (placa, navegador, tela) junto dos números — nenhum número sem a máquina.
- A última parte de cada arquivo é uma linha CSV com cabeçalho fixo: para comparar, cole as linhas numa planilha, uma embaixo da outra.
- A medição que vale para o orçamento é a da **máquina mais modesta do laboratório** (vídeo integrado).
